How to make the token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → this repo.
  3. Permissions: Contents = Read and write, Actions = Read and write.
  4. Paste it above. It never leaves your browser except to talk to GitHub.
Saved changes are used by the next scheduled run, or press “Run check now”.
